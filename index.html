Perguntas Frequentes

Posso levar alimentos para os animais?

Não. A alimentação dos animais é controlada pela equipe de biólogos e veterinários para garantir a saúde de todos.

O parque é acessível?

Este projeto prevê entrada gratuita para pessoas com deficiência. Confirme as condições de acessibilidade no site oficial.

Quanto tempo dura a visita?

Em média, de 2 a 3 horas para conhecer os principais recintos com calma.

Posso visitar com um grupo escolar?

Sim. Use o formulário de contato abaixo para solicitar o agendamento da turma.
